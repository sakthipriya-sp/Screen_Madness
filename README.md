Screen Madness
Overview
Screen Madness is a simple, elegant, and responsive website for browsing and viewing reviews of movies and series. Built using HTML, CSS, and Bootstrap, it focuses on providing an engaging and user-friendly interface for exploring the latest reviews.

Features
Movie and Series Listings:
Display movies and series with their respective posters, titles, genres, and ratings.

Responsive Design:
Ensures a seamless experience on devices of all sizes, including mobile, tablet, and desktop.

Review Section:
Users can view detailed reviews for each movie or series.

Search and Filter:
Provides the ability to filter content based on categories like genre, year, or rating.

Interactive Layout:
Uses Bootstrap components like cards, carousels, and modals for a visually appealing design.

Technologies Used
HTML5: For structuring the content.
CSS3: For styling and layout.
Bootstrap: For responsive and interactive design.
